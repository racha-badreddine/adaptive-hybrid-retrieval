# Adaptive Hybrid Retrieval

This repository contains code for adaptive hybrid retrieval systems combining dense and sparse retrieval methods.

## Project Structure

- `data/` - Dataset and data processing files
- `notebooks/` - Jupyter notebooks for exploration and analysis
- `src/` - Source code for core functionality
- `results/` - Experimental results and outputs
- `figures/` - Generated visualizations and figures
- `docs/` - Documentation
